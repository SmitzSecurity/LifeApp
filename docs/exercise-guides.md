# Exercise guide links

Verified September 16, 2026. The current exercise's information link resolves through `lib/life/exercise-guides.ts`. These are static external links only: opening a workout does not request any content, analytics, images or video from these providers. The app must open them only after an explicit click, in a separate tab with `rel="noopener noreferrer"`.

76 of the 79 built-in presets have a reviewed direct guide. MuscleWiki is the main provider; its [exercise library](https://musclewiki.com/exercises) describes video demonstrations and step-by-step guidance. Exact published page titles and exercise descriptions were checked against the preset, rather than producing URLs from preset slugs. Major lifts including bench press, squat, Romanian deadlift and overhead press also expose a linked tutorial. Other guides supplement the catalog when their exercise matches more closely. This is an outbound reference directory, not permission to embed or redistribute any provider's media.

The medium-grip/MAG pulldown, neutral-grip pulldown and chest-supported high-row variants currently use clearly labelled web searches because the reviewed source pages did not establish the precise requested variant. Custom or unrecognized qualifiers also use a search instead of a potentially incorrect illustration or tutorial. Known aliases use the shared exercise-name resolver while preserving equipment, grip and assisted/unassisted distinctions. A generic preset can link a common equipment variant of that movement; arbitrary custom variants are never reduced using substring matches.

The reverse-crunch guide uses Weight Training Guide's floor-based reverse crunch rather than MuscleWiki's page of that name, which describes a seated V-position movement. The assisted dip links Macros Inc's assisted-machine guide, independently of the seated dip machine's MuscleWiki guide.

## Verification

`node --test tests/exercise-guides.test.mjs` checks complete preset coverage, explicit search fallbacks, common aliases, grip/equipment/assistance separation, and escaping arbitrary custom names as search text. These are local mapping checks; they do not contact the websites during the test gate or promise that an external provider will never move a page.
