# UI removal candidates — awaiting owner approval

September 15, 2026. These are proposals only. This release changes spacing, typography and layout; every item below remains visible and functional. Nothing here authorizes a removal, new disclosure default, or change to saved data.

| ID | Existing item | Proposed later change | Why / what must remain |
| --- | --- | --- | --- |
| R1 | “Not recorded” beside an untouched daily habit | Remove just this visible label before a choice is made. | The unselected choices already convey the state. Keep the unrecorded value, completion rules and accessible state. |
| R2 | Disabled “Generate analysis” on an incomplete or missing day | Show the action when that day becomes eligible. | The explanation and Add/Finish entry link can guide the user meanwhile. Keep all eligibility checks and the generation action once eligible. |
| R3 | Home greeting “A new day, a little perspective.” | Remove the greeting and let the date and Start/Continue action lead. | It repeats on every visit and adds a heading before the useful content. Keep the date and entry action. |
| R4 | “Ready when you are” above the idle 0:00 workout timer | Remove this idle caption. | The workout title and current set identify the task. Keep active rest countdown/status and End rest. |
| R5 | “Use 0 for bodyweight.” under every working-set load field | Move this hint into contextual help. | Useful on first use, repetitive during each set. Keep bodyweight support, the unit and validation. |

Do not remove consent/provider context, error or unconfirmed-save notices, forecast-versus-recorded distinctions, debt estimate qualifications, or deletion confirmations as part of this list. Those affect the meaning of an action or its outcome.
